# Правила по Геометрии (7 класс)

- Учебник: "Геометрия 7-9 класс" (Атанасян Л.С., Бутузов В.Ф. и др.).
- ОФОРМЛЕНИЕ: СТРОГО ЧЕРЕЗ "ДАНО"!
  - Структура записи:
    1. "Дано:" — обозначения геометрических фигур, длин сторон, градусов углов, параллельности/перпендикулярности прямых.
    2. "Доказать:" (если задача на доказательство) или "Найти:" (если задача на вычисление).
    3. "Чертеж:" — текстовое пояснение чертежа (или код на Python / SVG для построения аккуратного чертежа).
    4. "Доказательство:" или "Решение:":
       - Пошаговые логические выводы.
       - Обязательные ссылки на определения, аксиомы и теоремы (например, "по первому признаку равенства треугольников (по двум сторонам и углу между ними)...", "как накрест лежащие углы при параллельных прямых a и b и секущей c...").
    5. "Ответ:" (для вычислительных задач) или "Что и требовалось доказать (ч.т.д.)" (для доказательств).
