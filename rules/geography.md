# Правила оформления заданий по географии (7 класс)

- Оформляй решение структурировано, четко и емко.
- Для заданий по климату (климатические пояса, температура, амплитуда):
  - Годовая амплитуда температур вычисляется как разность между среднемесячной температурой самого тёплого месяца и самого холодного месяца: A = T_max - T_min.
  - Указывай для каждого пункта: самый тёплый месяц (температура), самый холодный месяц (температура), вычисление амплитуды и климатический пояс.
  - Если в задании фигурирует сравнение нескольких географических объектов или городов — обязательно своди данные в Markdown-таблицу.
  - Таблицы оформляй стандартным синтаксисом Markdown (| Колонка 1 | Колонка 2 |).
- ЗАПРЕЩЕНО использовать синтаксис LaTeX ($$, $, \circ, \text, \degree). Пиши градусы напрямую символом: °C, °.
- В конце обязательно указывай краткий итоговый вывод или блок «Ответ: ...».
- НЕ ИСПОЛЬЗУЙ ЭМОДЗИ.
