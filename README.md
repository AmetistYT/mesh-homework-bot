# mesh-homework-bot

Автономный сервис на Rust для интеграции с электронным дневником МЭШ (school.mos.ru) и Telegram. Отслеживает домашние задания и цифровые тесты (ЦДЗ), решает их через выбранную языковую модель (по HTTP API или через CLI) с учетом школьных учебников и правил оформления, после чего упаковывает результат в адаптивные HTML-документы и публикует в рабочий чат.

Проект создан как semi vibecoded by gemini: практичный инструментарий для автоматизации рутины школьного дневника, написанный на Rust с акцентом на надежность, локальное хранение данных в SQLite и работу без зависаний.

---

## Архитектура и возможности

- **Два формата заданий**:
  - Обычные домашние задания: генерация решений по предметам, формулы, краткие конспекты параграфов и таблицы. Итоговый файл упаковывается в чистый мобильный HTML.
  - Цифровые домашние задания (ЦДЗ / тесты): строгая фильтрация только реальных тестов, решение вопросов (выбор одного/нескольких ответов, сопоставление, распределение по группам) с таймаутом на каждое задание. В отчете изначально открыты только задание и правильный ответ, а ход рассуждений и правила вынесены в сворачиваемые блоки.
- **Поддержка любых LLM-провайдеров по HTTP API**:
  - Любой сервис с OpenAI-совместимым эндпоинтом: OpenRouter, Google Gemini, OpenAI, Groq, DeepSeek, а также локальные Ollama или vLLM.
  - Поддержка запуска через Google Antigravity CLI (`agy`) локально или через SSH.
- **Работа с источниками и правилами**:
  - Поддержка чтения страниц оригинальных PDF-учебников через `pdftoppm`.
  - Отдельные файлы правил учителей в каталоге `rules/` (оформление «Дано/Найти/Решение/Ответ», требования к выводу формул, краткость без воды).
- **Интеграция с Telegram**:
  - Публикация ежедневных заданий по расписанию (по умолчанию в 15:00 каждый день, в пятницу — автоподбор заданий на понедельник).
  - Интерактивные инлайн-кнопки для просмотра и сдачи ЦДЗ прямо из мессенджера.
  - Логирование истории сообщений в SQLite, поиск по контексту, вызов модели через `!` и модерация участников по reply (`!мут 15 минут`, `!бан`).
- **Защита от сбоев**:
  - Санитизация сетевых ошибок МЭШ (исключает попадание служебных HTML-страниц 502/504 в Telegram-чат).
  - Таймауты на все сетевые запросы, защита от зависания процесса.

## Подключение LLM-провайдеров

Сервис поддерживает три режима работы через переменную `SOLVER_MODE` в файле `.env`:

### 1. Режим `SOLVER_MODE=api` (рекомендуемый)
Универсальное подключение к любой модели по OpenAI-совместимому протоколу. Бот отправляет стандартный запрос к эндпоинту `/chat/completions`.

#### OpenRouter (доступ ко всем моделям: Gemini, Claude, DeepSeek, Qwen)
```env
SOLVER_MODE=api
API_BASE_URL=https://openrouter.ai/api/v1
API_KEY=sk-or-v1-ваш-ключ
API_MODEL=google/gemini-2.5-flash
```

#### Официальный Google Gemini API (напрямую)
У Google Gemini есть нативный OpenAI-совместимый эндпоинт:
```env
SOLVER_MODE=api
API_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
API_KEY=AIzaSy...ваш_ключ_gemini
API_MODEL=gemini-2.5-flash
```

#### OpenAI (GPT-4o, GPT-4o-mini)
```env
SOLVER_MODE=api
API_BASE_URL=https://api.openai.com/v1
API_KEY=sk-proj-...
API_MODEL=gpt-4o-mini
```

#### Groq (быстрый бесплатный/дешевый инференс)
```env
SOLVER_MODE=api
API_BASE_URL=https://api.groq.com/openai/v1
API_KEY=gsk_...
API_MODEL=llama-3.3-70b-versatile
```

#### DeepSeek API
```env
SOLVER_MODE=api
API_BASE_URL=https://api.deepseek.com/v1
API_KEY=sk-...
API_MODEL=deepseek-chat
```

#### Локальный запуск (Ollama / vLLM / LM Studio)
Для полностью автономной работы без интернета и ключей:
```env
SOLVER_MODE=api
API_BASE_URL=http://localhost:11434/v1
API_KEY=ollama
API_MODEL=qwen2.5:14b
```

---

### 2. Режим `SOLVER_MODE=local` (через Antigravity CLI)
Используется, если на сервере установлен инструмент Google Antigravity CLI (`agy`):
```env
SOLVER_MODE=local
AGY_BIN=agy
AGY_MODEL=gemini-3.8-flash-medium
```

---

### 3. Режим `SOLVER_MODE=remote_ssh`
Запуск `agy` на выделенной машине через SSH:
```env
SOLVER_MODE=remote_ssh
SSH_HOST=192.168.1.100
SSH_USER=root
SSH_PORT=22
AGY_BIN=agy
AGY_MODEL=gemini-3.8-flash-medium
```

## Требования и установка

### 1. Системные зависимости
- **ОС**: Linux (Ubuntu, Debian, Arch Linux, Alpine и др.) или macOS.
- **Rust Toolchain** (версия 1.75 или новее):
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  source $HOME/.cargo/env
  ```
- **Системные библиотеки**:
  ```bash
  # Debian / Ubuntu:
  sudo apt update && sudo apt install -y pkg-config libssl-dev sqlite3 poppler-utils

  # Arch Linux:
  sudo pacman -S base-devel openssl sqlite poppler
  ```

---

### 2. Клонирование и настройка окружения

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AmetistYT/mesh-homework-bot.git
   cd mesh-homework-bot
   ```

2. Скопируйте шаблон переменных окружения:
   ```bash
   cp .env.example .env
   ```

3. Заполните `.env`:
   - `MESH_JWT_TOKEN`: Bearer-токен дневника МЭШ.
     - Как получить: откройте в браузере `school.mos.ru`, нажмите `F12` (Инструменты разработчика) -> вкладка **Сеть** (**Network**) -> найдите любой запрос к API dnevnik / school -> скопируйте значение заголовка `Authorization` (без слова `Bearer`).
   - `MESH_STUDENT_ID`: цифровой идентификатор профиля ученика (параметр `student_id` или `profile_id` в запросах дневника).
   - `TELEGRAM_BOT_TOKEN`: токен бота от `@BotFather`.
   - `TELEGRAM_CHANNEL_ID`: идентификатор группы или канала Telegram (например, `-1001234567890`). Добавьте бота в чат и выдайте права администратора (отправка сообщений, закрепление, отправка файлов).
   - `TELEGRAM_ADMIN_IDS`: ваш числовой Telegram ID для выполнения команд управления.
   - `SOLVER_MODE`, `API_BASE_URL`, `API_KEY`, `API_MODEL`: настройки выбранного провайдера модели (см. раздел выше).

---

### 3. Учебники и правила

1. **Учебники (опционально)**:
   Поместите сканы учебников в формате PDF в каталог, указанный в `TEXTBOOKS_DIR` (по умолчанию `textbooks_7_grade/`). Бот сопоставляет предмет с нужным файлом по названию предмета и извлекает страницы по номерам параграфов через `pdftoppm`.

2. **Правила преподавателей**:
   В каталоге `rules/` находятся инструкции в формате Markdown (`algebra.md`, `physics.md`, `geometry.md` и т.д.). Вы можете отредактировать их под требования ваших учителей.

---

### 4. Сборка и первый запуск

Соберите бинарный файл в режиме release:
```bash
cargo build --release
```

Запустите сервис для проверки:
```bash
./target/release/mesh-homework-bot
```

В логах отобразится подтверждение авторизации в МЭШ и запуск Telegram polling.

## Настройка фоновой службы systemd

Для круглосуточной непрерывной работы на Linux-сервере создайте unit-файл:

```bash
sudo nano /etc/systemd/system/mesh-homework-bot.service
```

Вставьте следующую конфигурацию (замените `/path/to/mesh-homework-bot` на реальный путь к каталогу):

```ini
[Unit]
Description=MESH Homework Solver Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/mesh-homework-bot
ExecStart=/path/to/mesh-homework-bot/target/release/mesh-homework-bot
Restart=always
RestartSec=10
Environment=RUST_LOG=info
Environment=RUST_BACKTRACE=1

[Install]
WantedBy=multi-user.target
```

Примените конфигурацию и запустите сервис:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now mesh-homework-bot.service
```

Просмотр журнала работы в реальном времени:
```bash
journalctl -u mesh-homework-bot.service -f
```

## Команды Telegram бота

### Основные команды
- `/dz` — получить и решить задания на завтра.
- `/dz <день недели>` — решение заданий на конкретный день (`/dz понедельник`, `/dz чт`, `/dz сегодня`, `/dz послезавтра`).
- `/dz <день> force` — принудительно перерешать день заново со сбросом сохраненного кэша.
- `/cdz` — список назначенных цифровых тестов с инлайн-кнопками для решения в HTML и последующей сдачи в МЭШ.
- `/cdz solve <ID>` — решить конкретный тест и получить интерактивный HTML-файл.
- `/cdz submit <ID>` — отправить сохраненные ответы теста в МЭШ и зафиксировать попытку.
- `/status` — статус сервиса, состояние токена авторизации и количество решенных задач.
- `/token <новый_токен>` — обновить JWT токен МЭШ на лету без перезапуска процесса.
- `/help` — список всех доступных команд.

### Диалог с моделью и модерация
- Обращение по `!` (например, `! реши задачу по физике`) — прямой запрос к модели. Модель помнит контекст диалога чата и имеет доступ к поиску по архиву переписки через локальную базу данных.
- `!/clear` (только для доверенного владельца) — сброс контекста диалога и начало новой чистой сессии.
- Модерация по ответу на сообщение: отправьте в reply нарушителю команду `!мут 15 минут`, `!мут 2 часа` или `!бан` — бот ограничит права автора исходного сообщения и автоматически восстановит их по таймеру.

## Структура проекта

```text
├── Cargo.toml                  # Зависимости и конфигурация сборки
├── .env.example                # Шаблон переменных окружения со всеми провайдерами
├── .gitignore                  # Исключения (учебники, токены, БД, бинарники)
├── src/
│   ├── main.rs                 # Точка входа, выбор режима solver и инициализация
│   ├── config.rs               # Чтение конфигурации и переменных окружения
│   ├── db/                     # Локальная база SQLite (кэш решений, история, токены)
│   ├── engine/                 # Планировщик (автозапуск в 15:00, открепление сообщений)
│   ├── mesh/                   # Взаимодействие с API МЭШ, авторизация, клиенты ЦДЗ
│   ├── solver/                 # Подготовка промптов, вызовы API / agy, парсинг ответов
│   │   ├── runner.rs           # Исполнитель LLM: HTTP API, Local CLI, Remote SSH
│   │   ├── cdz.rs              # Логика решения вопросов ЦДЗ с таймаутами
│   │   ├── cdz_html.rs         # Генерация интерактивного HTML-отчета по тестам
│   │   ├── html_export.rs      # Генерация HTML-отчета по домашним заданиям
│   │   └── humanizer.rs        # Очистка ответов от нейрослопа, Markdown-разметка
│   └── telegram/               # Telegram Bot API клиент, long polling, модерация
├── templates/
│   ├── cdz_template.html       # Интерактивный шаблон для тестов ЦДЗ
│   └── homework_template.html  # Шаблон ежедневного домашнего задания
├── rules/                      # Правила оформления по предметам (Markdown)
└── scripts/                    # CLI-утилиты для поиска по БД и синхронизации сессий
```

## Безопасность

- Никакие токены авторизации, пароли или сессионные куки не попадают в репозиторий: файл `.env`, рабочие базы данных `data/*.db` и сканы учебников исключены через `.gitignore`.
- При публикации в чат Telegram все ответы очищаются от системных промптов и внутренних служебных меток.
- Для безопасной работы в публичных группах команды изменения прав и очистки контекста защищены белым списком ID администраторов (`TELEGRAM_ADMIN_IDS`).
