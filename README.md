# МЭШ Homework Solver Bot

Автономный сервис на Rust для электронного дневника МЭШ (Московская электронная школа). Бот автоматически отслеживает домашние задания, решает их с помощью нейросетевого агента Antigravity CLI по сканам оригинальных школьных учебников и публикует результат в Telegram-группу класса.

В чате сохраняется идеальный порядок: бот присылает краткую сводку заданий в **закреп**, а все решения, конспекты и таблицы запекает в легковесный автономный **HTML-документ** для смартфонов (шрифт Nunito, мягкая ч/б тема, разворачиваемые аккордеоны, копирование в 1 клик).

---

## Возможности

- **Решение по реальным учебникам**: агент обращается к оригинальным страницам учебников и задачников (Перышкин, Лукашик, Макарычев, Атанасян, Starlight 7 и др.).
- **Модель Gemini 3.8 Flash Medium**: быстрый и точный инференс через Antigravity CLI (`agy --model gemini-3.8-flash-medium`).
- **Строго без воды**: решения формируются компактно — ровно то, что ученик переписывает в школьную тетрадь (Дано/Найти/Решение/Ответ, конспекты параграфов в 1–2 предложения).
- **Команды на любой день недели**: `/dz`, `/dz четверг`, `/dz пн`, `/dz пятница`, `/dz сегодня`, `/dz послезавтра`.
- **Сброс кэша и принудительное перерешивание**: `/dz четверг force`, `/dz перерешай`.
- **Умное расписание**: автозапуск каждый день в 15:00. В пятницу бот автоматически находит уроки понедельника и решает их заранее на все выходные.
- **Интерактивный мобильный экспорт**:
  - Адаптивные аккордеоны каждого предмета.
  - Нативные скроллящиеся таблицы (не ломают экран смартфона).
  - Кнопка «Копировать» у каждого решения.
  - Только нужные флаги (например, «ЦДЗ»), ничего лишнего.
- **Кэширование в SQLite**: решенные задачи сохраняются в базе и не тратят ресурсы при повторных запросах.

## Быстрый старт

### 1. Системные требования

- **Linux** (Ubuntu/Debian, Arch Linux и др.)
- **Rust** (1.75+):
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **Poppler utils** (для чтения страниц PDF учебников через `pdftoppm`):
  ```bash
  # Ubuntu / Debian
  sudo apt update && sudo apt install -y poppler-utils sqlite3

  # Arch Linux
  sudo pacman -S poppler sqlite
  ```
- **Antigravity CLI (`agy`)**:
  Утилита `agy` должна быть установлена и авторизована в системе:
  ```bash
  agy --version
  agy models
  ```

---

### 2. Настройка конфигурации

1. Скопируйте шаблон переменных окружения:
   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и укажите параметры:
   - `MESH_JWT_TOKEN`: токен авторизации МЭШ.
     - Как получить: откройте в браузере [school.mos.ru](https://school.mos.ru), нажмите `F12` -> вкладка **Network** (Сеть) -> найдите любой запрос к API дневника -> скопируйте значение заголовка `Authorization` (без слова `Bearer`).
   - `MESH_STUDENT_ID`: ID профиля ученика (число из запросов дневника, например `profile_id=12345678`).
   - `TELEGRAM_BOT_TOKEN`: токен вашего бота от `@BotFather`.
   - `TELEGRAM_CHANNEL_ID`: ID группы Telegram (для групп начинается с `-100...`).
     - Чтобы бот мог закреплять сообщения и отправлять файлы, выдайте ему права администратора в группе.
   - `AGY_MODEL`: `gemini-3.8-flash-medium` (по умолчанию).
   - `TEXTBOOKS_DIR`: путь к каталогу с учебниками (например `textbooks_7_grade`).

---

### 3. Добавление учебников

Поместите PDF-файлы учебников в папку `textbooks_7_grade/`:
- `Физика_7_класс_Перышкин.pdf`
- `Сборник_задач_по_физике_Лукашик.pdf`
- `Алгебра_7_класс_Макарычев.pdf`
- `Геометрия_7_9_Атанасян.pdf`
- `География_7_класс_Душина.pdf`
- `Starlight_7_Student_Book.pdf`

Бот автоматически находит нужный учебник по ключевым словам в названии предмета.

---

### 4. Сборка и запуск

Сборка оптимизированного бинарника:
```bash
cargo build --release
```

Запуск:
```bash
./target/release/mesh-homework-bot
```

## Настройка фонового сервиса (systemd)

Чтобы бот работал автономно 24/7 на сервере:

1. Создайте unit-файл `/etc/systemd/system/mesh-homework-bot.service`:
   ```ini
   [Unit]
   Description=MESH Homework Solver Telegram Bot
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/path/to/mesh-homework-bot
   ExecStart=/path/to/mesh-homework-bot/target/release/mesh-homework-bot
   Restart=always
   RestartSec=5
   Environment=RUST_LOG=info
   Environment=RUST_BACKTRACE=1

   [Install]
   WantedBy=multi-user.target
   ```

2. Включите и запустите сервис:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now mesh-homework-bot.service
   ```

3. Просмотр логов в реальном времени:
   ```bash
   journalctl -u mesh-homework-bot.service -f
   ```

## Команды Telegram бота

- `/dz` — получить и решить задания на завтра.
- `/dz <день недели>` — решение на любой день:
  - `/dz четверг`, `/dz пятница`, `/dz пн`, `/dz вт`, `/dz ср`, `/dz чт`, `/dz пт`, `/dz сб`, `/dz вс`.
- `/dz сегодня` — решение заданий на сегодня.
- `/dz <день> force` (или `/dz <день> перерешай`) — сбросить кэш базы данных и перерешать день заново с нуля.
- `/status` — состояние сервиса, валидность токена МЭШ, статистика решений.
- `/token <новый_jwt>` — обновление МЭШ токена прямо из Telegram без перезапуска сервиса.
- `/check` — принудительный запуск проверки дневника (для администратора).
- `/help` — список доступных команд.

## Настройка правил учителей (`rules/`)

В папке `rules/` находятся Markdown-файлы с инструкциями для нейросети:
- `algebra.md` — требования к уравнениям, запрет «Дано», построение графиков.
- `physics.md` — структура «Дано / СИ / Найти / Решение / Ответ», расшифровка «П.14» (Перышкин) и «Л.98» (Лукашик).
- `geometry.md` — формат доказательств, ссылки на теоремы.
- `geography.md` — формулы годовой амплитуды, климатические пояса, оформление таблиц.
- `english.md` — работа с текстами и диалогами Starlight 7.
- `general.md` — общее требование краткости без лишней воды.

Вы можете отредактировать любой файл под требования конкретного преподавателя вашей школы.
